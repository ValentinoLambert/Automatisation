# Racoin

Site de petites annonces (PHP / Slim 2 / Twig / Eloquent).

## Prérequis

- Docker & Docker Compose

## Démarrage

```bash
docker compose up -d --build
```

L'application est disponible sur **http://localhost:8080**

## Arrêt

```bash
docker compose down
```
